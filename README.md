## 项目简介
    当前项目主要为了解决电商行业生成素材问题，比如文生图，图生图，文生视频，图生视频，首尾帧视频（2张图片生成视频），全智能多帧视频。解决的是目前平台收费贵，对于刚起步小伙伴费用高问题。我这个项目支持自己配置平台API。自己部署本地电脑使用。也方便小     伙伴用AI进行二次开发。因为此项目大部分都是用AI开发的。
    未来还会扩展，画布功能和数字人等核心功能。目的就是给自己用和分析等。将不断持续扩展优化功能。
    
更加详细的产品信息请看产品需求文档： [产品需求](docs/prd/PRD.md)
