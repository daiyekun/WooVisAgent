面向个人的 AI 图影创作台：用最熟悉的对话方式提出需求，模型在你的账号下运行，作品自动归档。以下是全部页面原型，点击任意卡片即可进入体验。

Screens

五个页面，一条完整闭环

所有页面共用同一套深色设计系统，未登录状态下任何入口都会回到登录页。

登录
login.html

左侧品牌视觉 + 右侧账号密码表单，支持记住我、第三方登录与忘记密码。

  • 未登录不可进入创作台
  • 协议勾选为必选项
查看页面
注册
register.html

邮箱 + 验证码注册，含密码强度提示与协议确认，注册完成直接引导去配置模型。

  • 验证码 60 秒倒计时
  • 注册后落地到模型配置
查看页面
对话创作（主窗口）
app.html

类 WorkBuddy 的主窗口：左侧会话列表、中部对话流、底部输入区。图片与视频共用同一会话，用开关切换。

  • 图片模式：比例、参考图
  • 视频模式：分辨率、时长、首尾帧
  • 结果卡片可下载 / 复用 / 重绘
查看页面
我的作品
works.html

自己的历史生成结果全部在这里：类型与时间筛选、关键词搜索、网格 / 列表切换，悬停即可预览、下载或复用参数。

  • 图片 / 视频分类统计
  • 一键把参数带回创作台
查看页面
模型配置
models.html

图片模型与视频模型分开管理：填 Base URL 与 API Key，测连通性、设默认、存默认参数。平台不代收任何费用。

  • 服务商预设一键填充
  • 密钥可显隐，支持移除

这一版原型覆盖的范围
  • 账号体系：登录、注册
  • 核心创作：图片生成、视频生成（同一对话窗口内切换）
  • 历史资产：我的作品列表与检索
  • 模型接入：图片 / 视频模型 + 密钥与参数配置
开发落地时的注意点
  • 所有生成图与视频目前为占位块，接入接口后替换渲染层即可
  • 登录后需校验会话态，未登录一律重定向到 login.html
  • API Key 建议由后端加密存储，前端只做掩码展示
  • 不涉及积分与支付，费用由用户自己的模型服务商结算
